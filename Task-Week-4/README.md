1. Git adalah sistem pengontrol versi terdistribusi (Distributed Version Control System) yang digunakan untuk melacak setiap perubahan pada kode program. Dengan Git, 
  kita dapat melihat riwayat revisi, mengembalikan kode ke versi sebelumnya jika terjadi kesalahan, serta berkolaborasi dengan tim tanpa mengganggu atau menimpa pekerjaan anggota lain.
